# درب — تطبيق الراكب

تطبيق Flutter عربي باتجاه RTL لطلب سيارات الأجرة داخل العراق. النسخة الحالية تبني تدفق الراكب الأساسي، وتستخدم OpenStreetMap للخرائط وNominatim للبحث وOSRM للمسارات.

## تشغيل التطبيق

```powershell
flutter pub get
flutter run
```

لإنشاء APK تجريبي لمعمارية Android arm64:

```powershell
flutter build apk --debug --target-platform android-arm64
```

## الموجود حالياً

- خريطة تفاعلية مع اختيار الوجهة بالنقر، وإسناد OpenStreetMap.
- تنبيه واضح عند فتح التطبيق إذا كان الموقع متوقفاً أو الإذن غير ممنوح؛ يطلب إذن Android بعد ضغط المستخدم على «السماح بالموقع» وفق نمط طلب الإذن عند استخدام الميزة.
- مؤشر انطلاق على هيئة سهم يتجه وفق GPS ويتحدث مع حركة الجهاز، مع وضع تحريك الخريطة لضبط الانطلاق والوصول يدوياً.
- بحث جغرافي عن الأماكن، وحساب المسافة والمدة عبر OSRM.
- حفظ الوجهات الأخيرة والمفضلة محلياً لفتحها بنقرة واحدة.
- إضافة وإعادة ترتيب ما يصل إلى خمس نقاط توقف، ثم إعادة حساب المسار عبر OSRM.
- اختيار فئات السيارة والدفع النقدي كتجربة واجهة، مع عرض الأرقام بالعربية.
- حقل كوبون لا يطبّق خصماً قبل تحقق الخادم من صلاحيته.
- أيقونة مخصصة لتطبيقي Android وiOS، مع دعم Adaptive Icon على Android.
- مركز إشعارات داخل التطبيق وإشعارات محلية، وطلب إذن Android/iOS عند تفعيلها من الإعدادات.
- تسجيل OTP باسم ثلاثي ورقم عراقي، مع حفظ رمز الدخول في التخزين الآمن.
- مركز خدمة الزبائن وفئات لبلاغات سلوك الكابتن ونظافة وراحة السيارة والتكييف واختلاف الأجرة.
- نموذج تقييم/بلاغ لرحلة مكتملة عبر المسار `/rides/{rideId}/feedback`.
- صفحات الملف الشخصي وسجل الرحلات والإعدادات والوضع الليلي.
- رسائل واضحة عند عدم اتصال الخادم؛ لا تُنشأ رحلات أو حسابات أو سائقون تجريبيون.

## نقاط ربط الخادم المطلوبة

لا يتضمن المستودع Backend أو مشروع Firebase. لذلك لا يصل رمز OTP أو بلاغ أو إشعار قبول/رد حقيقي قبل ضبط الخدمات. إعدادات عنوان API موجودة في التطبيق؛ وتستخدم الواجهة عقداً أولياً لهذه المسارات:

- `POST /auth/otp/request` مع `full_name` و`phone`.
- `POST /auth/otp/verify` مع `phone` و`code`، ويعيد `access_token`.
- `POST /support/tickets` مع `category` و`details`.
- `POST /rides/{rideId}/feedback` مع `reasons` و`details`.

مركز الإشعارات يخزن الأحداث التي يستلمها التطبيق ويعرض إشعارات النظام عند منح الإذن، لكنه لا يستقبل Push بالخلفية بعد؛ يتطلب ذلك مشروع Firebase/FCM وربط الخادم برمز الجهاز. قبول الكابتن وموقعه ورقم/لون سيارته وإنشاء الرحلة والإلغاء وسجل الرحلات الفعلي تحتاج API الرحلات. أسعار الفئات المعروضة تقديرات تطوير وليست تعرفة عراقية.

تحفظ الوجهات الأخيرة والمفضلة التي يختارها المستخدم محلياً على الجهاز؛ لا تُحفظ إحداثيات GPS الحية في سجل المواقع الأخيرة.

خدمات Nominatim وOSRM العامة مناسبة للتطوير الأولي فقط. راجع شروط الاستخدام، وحدود الطلبات، وإسناد OpenStreetMap، واختر مزوداً مناسباً للإنتاج عند التوسع.
